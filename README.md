📊  Sistema de Controle Financeiro e Investimentos

Aplicação web desenvolvida em Python + Flask + PostgreSQL, com objetivo de controlar:

📈 Investimentos (Aportes e Dividendos)
💰 Movimentações Financeiras (Receitas e Despesas)
🏷 Cadastro de Ativos e Categorias
📊 Estrutura preparada para integração com Power BI

Projeto criado com foco em:

Organização financeira pessoal
Estrutura escalável
Portfólio profissional

🚀 Tecnologias Utilizadas
Python 3
Flask
PostgreSQL
psycopg2
Bootstrap 5
Render (deploy)
Git / GitHub
